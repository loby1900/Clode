# XFONX

تطبيق مشاركة صور متكامل (مستوحى من فكرة إنستجرام) بهوية بصرية وبراند مستقل تمامًا — فيد، بروفايل، لايكات، تعليقات، متابعة، وكل حاجة شغالة فعليًا. مبني بـ Node.js + Express + SQLite، بدون أي تكلفة تشغيل.

## المميزات
- تسجيل / دخول بـ JWT + تشفير كلمات المرور (bcrypt)
- رفع صور ونشر بوستات (JPG/PNG/WEBP/GIF، حتى 8MB)
- فيد لا نهائي (infinite scroll) بالتمرير للأسفل
- لايك/إلغاء لايك، تعليقات
- متابعة/إلغاء متابعة
- بروفايل شخصي قابل للتعديل (صورة + نبذة) وبروفايلات المستخدمين التانيين
- تصميم موبايل-فيرست، خط عربي RTL، ثيم فاتح وغامق تلقائي

## التشغيل محليًا (مجانًا بالكامل)

يحتاج فقط [Node.js](https://nodejs.org) نسخة 18 أو أحدث — مفيش أي خدمة مدفوعة.

```bash
npm install
cp .env.example .env     # عدّل JWT_SECRET لو حابب
npm start
```

افتح المتصفح على `http://localhost:3000` وهتلاقي صفحة تسجيل الدخول.

قاعدة البيانات (SQLite) بتتخزن في `data/xfonx.db` والصور المرفوعة في `uploads/` — كله بيتعمله حفظ تلقائي، مفيش سيرفر خارجي أو اشتراك مطلوب.

## رفعه أونلاين مجانًا

التطبيق خفيف وممكن يتنشر مجانًا على أي من دول:

| المنصة | ملاحظات |
|---|---|
| [Render](https://render.com) (Free Web Service) | اربط الريبو، الأمر `npm start`، هيدي لك رابط عام |
| [Railway](https://railway.app) | نفس الفكرة، فيه free tier شهري |
| [Fly.io](https://fly.io) | يحتاج `fly launch` بس برضه مجاني للمشاريع الصغيرة |

⚠️ ملحوظة: الخطط المجانية لحد دلوقتي بتـ"ينام" السيرفر فيها لو مفيش زيارات لفترة، وبعض المنصات بتمسح أي ملفات اتحفظت على الـ disk (زي `data/xfonx.db` و`uploads/`) كل مرة يعاد نشر السيرفر. لو عايز الداتا تفضل محفوظة بشكل دائم أونلاين، هتحتاج تضيف قاعدة بيانات مُدارة مجانية زي [Turso](https://turso.tech) أو تخزين صور خارجي زي [Cloudinary](https://cloudinary.com) (كلاهما بيدي free tier سخي) — التطبيق حاليًا شغال بـ SQLite محلي عشان يكون أبسط حاجة ممكنة تتشغل فورًا من غير أي حساب أو API key.

## هيكل المشروع

```
src/
  server.js          نقطة الدخول + الراوتس
  db.js              إعداد قاعدة بيانات SQLite والجداول
  middleware/
    auth.js          تحقق JWT
    upload.js        رفع الصور (multer) + فلترة النوع والحجم
  routes/
    auth.js           تسجيل / دخول / بيانات المستخدم الحالي
    posts.js           بوستات، لايكات، تعليقات
    users.js            بروفايلات، متابعة، تعديل البروفايل
public/
  index.html          صفحة تسجيل الدخول / إنشاء حساب
  feed.html            الفيد الرئيسي
  profile.html         صفحة البروفايل
  css/style.css        كل التنسيقات (براند XFONX الأصلي)
  js/api.js             طبقة التواصل مع الـ API
  js/nav.js              الشريط العلوي/السفلي والمودال المشترك
```

## حقوق الملكية

الاسم "XFONX" والهوية البصرية (الألوان، الشعار، التصميم) أصلية بالكامل ومفيش فيها أي جزء من شعار أو تصميم إنستجرام الحقيقي — بس الفكرة العامة (فيد صور، بروفايل، لايك/تعليق/متابعة) هي نفس فكرة تطبيقات مشاركة الصور المعروفة بشكل عام.
